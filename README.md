# 家教单匹配助手

一个基于 **Python、Streamlit 和高德地图 Web 服务 API** 的个人家教信息筛选工具。

将微信群等渠道中的家教消息复制到页面，工具会提取科目、年级、地址、报酬和教师要求，结合个人偏好与预计通勤时间，帮助你筛选和比较家教单。

适用于需要在多个家教群中查找订单、比较报酬和出行成本的使用者。

## 功能介绍

### 多格式消息识别

- 支持多条家教消息批量粘贴。
- 支持不同字段名称，例如“科目／辅导科目”“课酬／课时费／薪资价格”。
- 支持编号位于开头或末尾，以及带编号的无标签逐行描述。
- 提取科目、年级、学生情况、上课地址、时间、教师要求及报酬。
- 保留原文、字段识别依据和未归类内容，方便人工核对。
- 同编号、相同文本去重；同编号的不同内容保留为多个版本。

### 个性化匹配

可设置可教科目、年级、是否接受全科或作业辅导、最低时薪、出发位置和最长单程通勤时间。

结果分为：

- **全部**：查看所有已识别订单。
- **候选，待确认**：没有发现明确冲突，但仍需核实教师要求、报酬或通勤等信息。
- **不符合**：存在明确不符合条件的内容，并展示原因。

支持价格优先、通勤优先，以及单独按价格或通勤排序。价格按明确时薪下限比较；未知价格或通勤在对应排序维度中排后。

### 报酬归一化

| 原始报价 | 处理方式 |
| --- | --- |
| `120–150/h` | 时薪120–150元 |
| `120/次，一次2h` | 折算为60元/小时 |
| `220–240/2h` | 折算为110–120元/小时 |
| `135/1.5h` | 折算为90元/小时 |
| `老师报价，一次2h` | 报酬待确认，单次时长2小时 |
| `120小时` | 单位不明确，保留原文并提示核对 |

“分科授课”允许按可教科目申请；“陪读”的实际辅导范围保持待确认，不直接认定为全科教学。

### 路线与通勤查询

接入高德地图，根据起终点和交通方式查询路线：

- 公共交通（公交＋地铁）
- 地铁＋步行
- 公交＋步行
- 步行
- 打车（使用驾车路线估算行程时间）

展示返回方案中的预计全程时间、路线距离、步行距离、换乘信息和路线步骤，并推荐其中预计用时最短的方案。公共交通可指定出发日期和时间。

起点和终点可修改。输入修改后按回车或离开输入框，定位就绪时会自动查询。宽泛地址或多个定位结果需要补充地址或确认定位。

当前地址查询支持广州和佛山，公共交通查询会传递起终点城市。跨城方案是否可用，以接口实际返回结果为准。

### 本地保存

- 使用 SQLite 保存订单及其版本。
- 重复保存相同版本不会重复新增。
- 支持查看已保存记录和下载本次解析结果为 JSON。
- 地图查询结果在当前会话缓存5分钟，可手动刷新。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Python | 消息解析、匹配和排序 |
| Streamlit | 页面与交互 |
| SQLite | 本地订单保存 |
| 高德地图 Web 服务 API | 地址定位和路线查询 |

消息识别目前采用本地规则与内容特征分析，**尚未接入大语言模型**。

## 项目结构

以下结构以项目代码位于 `tutor_matcher/` 文件夹为例：

```text
tutor_matcher/
├── app.py              # 页面、偏好设置与交互
```

## 安装与启动

### 1. 准备环境

建议使用 Python 3.11或3.12。下载或克隆仓库后，在 PowerShell 中进入包含 `app.py` 和 `requirements.txt` 的目录。

如果代码位于仓库的 `tutor_matcher/` 文件夹：

```powershell
cd tutor_matcher
```

检查 Python：

```powershell
py --version
```

### 2. 创建虚拟环境并安装依赖

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果系统没有 `py`，但 `python --version` 可用，将创建环境的命令改为：

```powershell
python -m venv .venv
```

安装和启动均使用虚拟环境中的解释器，避免依赖安装到其他 Python 环境。无需执行环境激活脚本。

### 3. 启动页面

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器通常会自动打开页面；如果没有打开，访问终端显示的本地地址，通常为 `http://localhost:8501`。

在终端按 `Ctrl+C` 停止程序。下次使用只需重新执行启动命令。

### macOS / Linux

在包含 `app.py` 的目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

## 配置高德地图

1. 注册或登录 [高德开放平台控制台](https://console.amap.com/)。
2. 在应用管理中创建应用。
3. 添加 Key，服务平台选择 **Web服务**。
4. 在助手左侧填写 Key，并检查账户的服务权限与调用配额。

Key 仅用于当前会话，不写入订单数据库。地图查询会将地址及坐标发送给高德。

未填写 Key 时，仍可进行消息识别、科目／年级／报酬筛选和价格排序，通勤显示为待确认。

## 使用步骤

1. **设置个人偏好**：填写出发位置、可教科目与年级、最低时薪和最长单程通勤时间。
2. **导入消息**：将多条家教消息粘贴到“导入家教消息”区域，替换示例内容。
3. **核对识别结果**：检查科目、年级、价格及教师要求；必要时展开原文依据。
4. **设置出行方式**：填写高德 Key，选择公共交通、地铁、公交、步行或打车。
5. **核对起终点**：建议使用具体校门、小区入口或地标。上课终点可直接修改。
6. **查看路线**：定位就绪后自动查询，展示推荐方案及其他返回方案。
7. **筛选和排序**：切换“候选，待确认”等分类，选择价格或通勤优先级。
8. **保存或导出**：将订单保存到本地数据库，或下载本次解析结果。

候选表示值得进一步核实，**不代表已完全符合要求或订单仍可接**。

## 测试

在代码目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试覆盖多格式拆单、同义字段、报价折算、重复与变更版本、分科匹配、未知值排序及地图返回数据处理。

地图单元测试使用模拟数据；通过测试不等于完成真实 API 联调，需要使用自己的 Key 验证实际定位和路线结果。

## 当前边界

- 规则解析仍可能误分或漏识别严重省略、错别字较多或订单边界不清的消息，请核对原文。
- 教师性别、学校、专业、成绩和经验等要求保留原文，由使用者判断。
- 上课时间目前以原文展示，不会自动检测全部课程时间冲突。
- 同编号存在不同版本时，保留全部内容；当前按首个版本筛选，不自动判断哪个更新。
- 手工修改的查询终点保留在当前会话，尚未写入订单数据库。
- 推荐是在接口返回的有限方案中比较，不保证涵盖所有可行路线。
- 通勤是预计时间，受定位精度、班次、候车和交通状况影响；打车时间不含叫车等待时间。
- 本项目通过手动粘贴导入消息，不自动读取微信聊天，也不自动联系发布者。

## 上传 GitHub 时的数据管理

建议在仓库根目录添加 `.gitignore`，避免提交本地环境和真实订单数据：

```gitignore
.venv/
__pycache__/
*.pyc
*.db
*.db-*
.env
.streamlit/secrets.toml
orders.json
```

公开仓库中的示例消息应使用虚构或充分脱敏的数据，不包含真实联系方式、学生身份或详细住宅地址。不要将地图 Key 写入代码或截图。
